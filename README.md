# School International Training

Tranonkala fampisehoana amin'ny teny anglisy sy frantsay, momba ny sekoly foronina iray any New Brunswick.

## Mombamomba ny tetikasa

Ity tetikasa ity dia mampiseho tranonkala akademika azo ampiasaina amin'ny fitaovana samihafa, ahitana:
- Fampisehoana amin'ny teny anglisy sy frantsay
- Fandaharana akademika santionany
- Taratasy fangatahana fidirana
- Rafitra fanaraha-maso fangatahana santionany

**Fanamarihana:** Tetikasa fampisehoana ihany ity fa tsy sekoly tena misy. Tsy mandefa na mitahiry fangatahana ilay taratasy, ary angona santionany efa voafaritra mialoha no ampiasaina amin'ny fanaraha-maso.

## Teknolojia ampiasaina

- HTML5
- CSS3
- JavaScript
- Docker
- Docker Compose
- Nginx

## Firafitry ny tetikasa

```text
.
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
├── Dockerfile
├── compose.yaml
├── .dockerignore
├── index.html
└── README.md

```
## Fampandehanana ny tetikasa

Manamboatra sy mampandeha ny tetikasa:

docker compose up -d --build

Manamarina ny satan'ny container:

docker compose ps

Sokafy amin'ny navigateur:

http://localhost:8080

## Fampitsaharana ny tetikasa

Mampitsahatra ny container:

docker compose down

## Toetry ny tetikasa

Mbola tranonkala fampisehoana ny lafiny ivelany (frontend) ity tetikasa ity, ary ampandehanin'ny Nginx ao anaty Docker container.

Mbola tsy nampidirina ny backend, ny database, ny fikirakirana fangatahana fidirana tena izy, ary ny fandoavam-bola amin'ny Internet.
